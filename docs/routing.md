# Пешеходные маршруты

## Что нужно backend

1. **Матрица пешего времени** между стартом и магазинами, чтобы выбрать порядок обхода (F09).
2. **Линия маршрута по улицам** для выбранного плана, чтобы iOS нарисовала её на карте.

Показ самой карты в приложении остаётся задачей iOS-разработчика.

## Почему не API Яндекса

Серверные API Яндекса платные, и использовать их команда не будет: [Distance Matrix](https://yandex.ru/maps-api/products/distancematrix-api)
и [Router API](https://yandex.ru/maps-api/products/router-api) стоят от 195 000 ₽ в год каждый
(проверено 30.10.2026), бесплатного тарифа нет.

## Решение: свой OSRM

[OSRM](https://project-osrm.org/) работает на наших серверах и на картах OpenStreetMap: бесплатно, без лимитов
и без ключей, а координаты пользователей не уходят третьей стороне.

Сравнение 05.11.2026 на одной карте Петербурга:

| Вариант | Цена и лимиты | Матрица | Вывод |
|---|---|---|---|
| **OSRM** (свой) | бесплатно, без лимитов | есть (`/table`) | **выбран**: уже работает и проверен |
| [Valhalla](https://valhalla.github.io/valhalla/api/matrix/api-reference) (свой) | бесплатно, без лимитов | есть | равноценная замена, см. замер |
| [openrouteservice](https://openrouteservice.org/restrictions/) (чужой сервер) | [2000 маршрутов и 500 матриц в сутки, 40 в минуту](https://openrouteservice.org/plans/) | есть | запасной вариант: лимиты, нужен ключ, координаты уходят наружу |
| [GraphHopper](https://discuss.graphhopper.com/t/matrix-requests-on-local-install/7279) (свой) | бесплатно | HTTP-матрица только в платном API | не подходит: без матрицы нет порядка обхода |

Замер OSRM и Valhalla на настоящих точках: старт у метро «Комендантский проспект» и 20 магазинов команды.

| Показатель | OSRM | Valhalla |
|---|---|---|
| Средний путь от метро до магазина | 1302 м | 1336 м |
| Среднее время | 15,6 мин | 15,9 мин |
| Матрица 21 × 21 | 54 мс | 61 мс |
| Линия маршрута | 2–3 мс | 6–10 мс |
| Память в работе | 276 МБ | 244 МБ |
| Граф на диске | 344 МБ | 114 МБ |

На проспекте линии совпадают, разница около 40 м. Различия только во дворах: у «Колхоза» OSRM короче
на 342 м, потому что срезает дворами, а Valhalla обходит. Какой путь верный, без проверки ногами сказать
нельзя. Выигрыша, ради которого стоило бы менять проверенный движок, нет. Valhalla стоит вернуть,
если понадобятся текстовые подсказки поворотов на русском: провайдеры скрыты за интерфейсом
`RoutingProvider`, поэтому замена затронет только `app/routing/`.

## Кто отвечает за красоту линии

Backend отдаёт форму линии: около 100 точек на 2 км, идущих по настоящим дорожкам. Цвет, толщину, скругления
и маркеры рисует клиент. Для аккуратного вида на iOS: скругление углов (`lineJoin` и `lineCap` round),
белая подложка под линией и числа на маркерах. Магазин стоит в здании, а линия заканчивается на ближайшей
дорожке, поэтому маркер бывает на несколько метров в стороне от линии. Это нормально.

## Проверка по Петербургу (30.10.2026)

Карта: выгрузка OpenStreetMap для Санкт-Петербурга с [BBBike](https://download.bbbike.org/osm/bbbike/SanktPetersburg/) от 24.10.2026 (54 МБ).

| Маршрут | По прямой | Пешком | Время |
|---|---|---|---|
| ИТМО (Кронверкский, 49) → м. Горьковская | 595 м | 930 м | 11 мин |
| ИТМО → Дворцовая площадь (через мост) | 2,0 км | 2,8 км | 34 мин |
| Пятилеток, 2 → Большевиков, 19 | 653 м | 806 м | 10 мин |
| Ударников, 34 → Пятилеток, 2 | 2,8 км | 3,0 км | 37 мин |
| Петропавловская крепость → Дворцовая наб. напротив | 475 м | 2,2 км | 27 мин |

- Расстояния и время совпадают с реальностью; скорость пешехода в профиле 5 км/ч.
- Через Неву маршрут идёт только по мостам: в последней строке 475 м по прямой превращаются в 2,2 км.
- Линия маршрута подробная: 60–190 точек на 1–3 км.
- Матрица 6 × 5 считается примерно за 70 мс, расчёт плана целиком через API: 80–270 мс.

Проверено и сквозным сценарием: регистрация, корзина из 5 товаров, расчёт планов на демо-каталоге
с реальными маршрутами OSRM через HTTPS (Caddy) в продакшен-конфигурации Docker Compose.

## Ограничения, о которых стоит знать

- **Разводные мосты.** OSRM не знает, что ночью (примерно с 1 до 5 часов, апрель–ноябрь) мосты через
  Неву разведены. Пилот проходит в одном районе, поэтому это не мешает, но для маршрутов через Неву
  ночью оценка будет неверной.
- **Свежесть карты.** Карта обновляется запуском `./deploy/osrm/prepare.sh`. Раз в месяц достаточно.
- **Магазины команды разбросаны по городу.** В черновой таблице пешком от Малого проспекта В.О.
  до проспекта Пятилеток почти 3 часа. По ТЗ пилот должен быть в одном районе, иначе планы из
  нескольких магазинов не уложатся в лимит времени.

## Как запустить

```bash
./deploy/osrm/prepare.sh                      # скачать карту и построить граф
docker compose --profile routing up -d osrm   # локально: http://localhost:5001
```

В `.env`: `ROUTING_PROVIDER=osrm`, `OSRM_BASE_URL=http://localhost:5001`
(внутри Docker адрес `http://osrm:5000` подставляется автоматически).

Быстрая проверка: `curl "http://localhost:5001/route/v1/foot/30.3084,59.9571;30.3189,59.9561"`.
Обратите внимание: OSRM принимает координаты в порядке **долгота, широта**, а Яндекс в порядке широта, долгота.
Адаптеры переводят их сами, остальной код работает с `GeoPoint(latitude, longitude)`.
